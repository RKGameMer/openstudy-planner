# OpenStudy Planner 页面信息架构与低保真页面说明 v0.1

**依据文档：**《OpenStudy Planner MVP 产品需求文档 v0.1》
**设计阶段：** 页面原型前的信息架构与低保真说明
**适用范围：** 第一版MVP
**设计原则：** 不增加MVP功能，不引入账号、AI、统计、计时器、日历排程或自动顺延机制

---

# 1. 页面信息架构

## 1.1 一级页面

第一版只设置三个一级页面：

1. **今日**
2. **任务库**
3. **数据与说明**

三个一级页面构成产品的全部主导航。

用户不需要登录，打开产品后默认进入“今日”页面。

## 1.2 二级界面

以下界面用于完成具体操作，不作为一级导航入口：

1. **新建／编辑任务界面**
2. **任务详情界面**
3. **从现在重新安排界面**
4. **导入文件预览界面**
5. **永久删除确认对话框**
6. **清除本地数据确认对话框**
7. **操作结果提示**

其中：

* 新建和编辑任务使用同一个表单结构；
* 任务详情和编辑可以在同一个二级页面中完成；
* 手机端可使用全屏二级页面；
* 桌面端可使用侧边抽屉或居中弹层；
* 无论采用哪种视觉形式，功能和字段必须保持一致。

## 1.3 页面关系

```text
打开产品
   ↓
今日
 ├─ 新建任务
 ├─ 打开任务详情／编辑
 ├─ 修改任务状态
 ├─ 从现在重新安排
 └─ 跳转任务库

任务库
 ├─ 新建任务
 ├─ 打开任务详情／编辑
 ├─ 加入今日重点
 ├─ 移出今日重点
 ├─ 查看已完成任务
 ├─ 查看已移除任务
 └─ 永久删除任务

数据与说明
 ├─ 导出数据
 ├─ 选择导入文件
 │    └─ 导入预览与确认
 ├─ 清除本地数据
 │    └─ 二次确认
 └─ 查看隐私、安全、版权和产品范围说明
```

# 2. 全局导航与通用结构

## 2.1 移动端导航

移动端使用固定在页面底部的三个导航入口：

* 今日
* 任务库
* 数据与说明

要求：

* 每个入口同时显示文字和简单图标；
* 当前所在页面有明确选中状态；
* 主要操作不得只依赖图标表达；
* 底部导航不得遮挡页面按钮或任务内容。

## 2.2 桌面端导航

桌面端可以使用：

* 左侧导航栏；或
* 页面顶部导航栏。

无论使用哪种形式，都只显示三个一级入口，不新增：

* 统计；
* 日历；
* 个人中心；
* 成绩；
* AI助手；
* 设置中心。

## 2.3 全局反馈方式

所有页面使用一致的操作反馈：

### 成功反馈

适用于：

* 任务保存成功；
* 状态修改成功；
* 重新安排成功；
* 数据导出成功；
* 数据导入成功；
* 本地数据清除成功。

反馈应简短，例如：

* “任务已保存”
* “已加入今日重点”
* “重新安排已应用”
* “数据已恢复”

成功提示不应阻断用户继续操作。

### 失败反馈

适用于：

* 本地数据读取失败；
* 保存失败；
* 导入文件无效；
* 导入写入失败；
* 清除失败；
* 浏览器本地存储不可用。

失败反馈必须：

* 说明操作没有成功；
* 说明现有数据是否仍然保留；
* 提供重试或返回入口；
* 不使用“未知错误”作为唯一说明。

### 危险操作确认

以下操作必须二次确认：

* 永久删除任务；
* 使用导入文件替换当前数据；
* 清除当前浏览器中的应用数据。

# 3. 页面一：今日

## 3.1 页面目的

“今日”页面用于帮助用户：

1. 查看当前选择的今日重点；
2. 快速创建并开始一个任务；
3. 修改任务执行状态；
4. 在计划偏离后进入“从现在重新安排”；
5. 处理过往仍未决定的重点任务。

该页面不展示：

* 总学习时长；
* 倒计时；
* 番茄钟；
* 连续打卡；
* 完成率图表；
* 成绩趋势；
* 科目分布图；
* 效率评分。

## 3.2 页面区域

### 区域A：页面标题

包含：

* 页面名称“今日”；
* 当前日期；
* 简短说明，例如“先处理当前最重要的任务”。

不包含：

* 天气；
* 倒计时；
* 距离考试天数；
* 用户头像；
* 登录状态。

### 区域B：快速新建任务

包含：

* 任务名称输入框；
* “添加”按钮；
* “补充信息”入口。

默认情况下，用户输入一个非空任务名称即可直接保存。

“补充信息”打开统一任务表单，用户可以选择性填写：

* 科目；
* 学习形式；
* 内容范围；
* 下一步；
* 完成标准；
* 计划日期；
* 备注。

从“今日”页面快速新建的任务，默认加入今日重点。

保存按钮附近必须明确显示：

> 保存后加入今日重点

用户如不希望加入今日重点，可以在补充信息界面取消该选项。

### 区域C：过往重点待处理提示

只有存在过往重点且用户尚未重新决定时显示。

提示内容示例：

> 有2项过往重点仍未处理

提供一个操作：

* “去处理”

点击后进入“从现在重新安排”界面。

该提示不得：

* 自动把任务加入今天；
* 自动把任务延期；
* 自动修改计划日期；
* 阻止用户继续使用其他功能。

### 区域D：今日重点任务列表

展示当天由用户主动加入今日重点的任务。

每个任务卡片包含：

* 任务名称；
* 科目标签，可选；
* 学习形式标签，可选；
* 当前状态；
* 下一步，可选；
* 完成标准，可选；
* 主要操作按钮；
* 更多操作入口。

主要操作根据状态变化：

| 当前状态 | 主要操作       |
| ---- | ---------- |
| 待处理  | 开始         |
| 进行中  | 部分完成、完成    |
| 部分完成 | 继续、完成      |
| 已完成  | 查看         |
| 已移除  | 不在今日重点列表显示 |

每个任务的更多操作可包括：

* 编辑；
* 移出今日重点；
* 标记为待处理；
* 标记为已移除。

不得在任务卡片中加入：

* 专注计时；
* 自动预计完成时间；
* AI建议；
* 学习评分；
* 任务难度评分。

### 区域E：重点数量建议

用户添加第1至第3项重点时，不显示警告。

当用户准备添加第4项及以上重点时，显示一次非阻断提醒：

> 建议保留1—3项当前重点，你仍然可以继续添加。

操作选项：

* 继续添加；
* 返回查看当前重点。

不得：

* 禁止添加；
* 自动删除其他重点；
* 要求用户先完成现有任务；
* 根据预计用时判断是否允许添加。

### 区域F：从现在重新安排入口

当今日重点中存在以下状态的任务时显示：

* 待处理；
* 进行中；
* 部分完成。

按钮文字：

> 从现在重新安排

点击后进入重新安排界面。

该入口由用户主动触发，不在特定时间自动弹出。

## 3.3 用户可执行的操作

用户可以：

* 快速新建任务；
* 打开完整任务表单；
* 将新任务加入今日重点；
* 开始任务；
* 标记部分完成；
* 标记完成；
* 恢复为待处理；
* 打开任务详情；
* 编辑任务；
* 移出今日重点；
* 进入“从现在重新安排”；
* 处理过往未决定任务；
* 跳转到任务库。

## 3.4 页面跳转

| 用户操作        | 跳转结果        |
| ----------- | ----------- |
| 点击任务名称或任务卡片 | 打开任务详情／编辑界面 |
| 点击补充信息      | 打开新建任务完整表单  |
| 点击去处理       | 进入从现在重新安排   |
| 点击从现在重新安排   | 进入从现在重新安排   |
| 点击任务库导航     | 进入任务库       |
| 点击数据与说明导航   | 进入数据与说明     |

状态修改成功后，用户停留在今日页面。

## 3.5 低保真结构

```text
┌─────────────────────────┐
│ 今日             当前日期 │
│ 先处理当前最重要的任务     │
├─────────────────────────┤
│ [输入任务名称……]   [添加] │
│ [补充信息] 保存后加入今日重点│
├─────────────────────────┤
│ 有2项过往重点仍未处理       │
│                    [去处理]│
├─────────────────────────┤
│ 今日重点                  │
│                         │
│ 任务卡片1                 │
│ 数学 · 刷题 · 待处理       │
│ 下一步：完成第1—5题        │
│ 完成标准：订正错误题        │
│          [开始] [更多]     │
│                         │
│ 任务卡片2                 │
│ 英语 · 复习 · 部分完成     │
│          [继续] [完成]     │
├─────────────────────────┤
│ [从现在重新安排]           │
├─────────────────────────┤
│ 今日｜任务库｜数据与说明    │
└─────────────────────────┘
```

## 3.6 空状态

### 情况A：应用中没有任何任务

显示：

> 还没有学习任务
> 先写下一件需要完成的事，只填写任务名称也可以。

操作：

* “新建第一个任务”

同时保留快速新建输入框。

### 情况B：任务库有任务，但今日重点为空

显示：

> 今天还没有选择重点
> 你可以从任务库选择任务，或直接创建一个新任务。

操作：

* “从任务库选择”
* “新建任务”

不得自动替用户选择任务。

### 情况C：今日重点全部完成

显示：

> 当前重点已经处理完毕

可提供：

* “查看任务库”

不得显示：

* 完成率；
* 连续天数；
* 奖励动画；
* 自动推荐下一项任务。

## 3.7 错误状态

### 本地数据读取失败

显示：

> 无法读取当前浏览器中的任务数据。请尝试重新加载页面。现有数据不会被自动覆盖。

操作：

* “重新加载”
* “前往数据与说明”

在读取状态未明确前，不允许新数据覆盖未知的现有数据。

### 保存失败

显示：

> 任务没有保存成功。请检查浏览器是否允许本地存储，然后重试。

保留用户已输入内容。

操作：

* “重试保存”
* “取消”

### 状态修改失败

显示：

> 状态没有修改成功，任务仍保持原状态。

操作：

* “重试”

# 4. 页面二：任务库

## 4.1 页面目的

“任务库”用于集中查看和管理全部任务，包括：

* 活跃任务；
* 已完成任务；
* 已移除任务。

该页面负责管理任务，不负责生成统计报告或日历计划。

## 4.2 页面区域

### 区域A：页面标题与新建入口

包含：

* 页面名称“任务库”；
* “新建任务”按钮。

点击后打开统一的新建任务界面。

### 区域B：状态筛选

第一版提供以下状态筛选：

* 活跃；
* 待处理；
* 进行中；
* 部分完成；
* 已完成；
* 已移除。

“活跃”包含：

* 待处理；
* 进行中；
* 部分完成。

第一版不提供：

* 自定义筛选；
* 多条件组合筛选；
* 全文搜索；
* 标签管理；
* 复杂排序；
* 看板视图；
* 日历视图。

### 区域C：任务列表

每个任务条目显示：

* 任务名称；
* 科目，可选；
* 学习形式，可选；
* 计划日期，可选；
* 当前状态；
* 是否属于今日重点；
* 主要操作；
* 更多操作。

主要操作根据任务状态显示：

| 情况        | 主要操作    |
| --------- | ------- |
| 活跃且不在今日重点 | 加入今日重点  |
| 活跃且已在今日重点 | 移出今日重点  |
| 已完成       | 查看或重新打开 |
| 已移除       | 恢复      |
| 任意状态      | 打开详情    |

永久删除放在更多操作中，不作为默认主要按钮。

### 区域D：第4项重点提醒

如果用户从任务库加入任务后，今日重点将达到第4项或以上，显示非阻断提醒：

> 建议保留1—3项当前重点，你仍然可以继续添加。

用户选择“继续添加”后完成操作。

## 4.3 用户可执行的操作

用户可以：

* 新建任务；
* 查看任务；
* 编辑任务；
* 按状态筛选；
* 加入今日重点；
* 移出今日重点；
* 开始任务；
* 修改任务状态；
* 恢复已完成任务为待处理；
* 恢复已移除任务；
* 永久删除任务；
* 跳转今日页面；
* 跳转数据与说明页面。

## 4.4 页面跳转

| 用户操作      | 跳转结果          |
| --------- | ------------- |
| 点击新建任务    | 打开新建任务界面      |
| 点击任务条目    | 打开任务详情／编辑界面   |
| 点击加入今日重点  | 保持当前页面并更新任务状态 |
| 点击移出今日重点  | 保持当前页面并更新显示   |
| 点击今日导航    | 返回今日页面        |
| 点击数据与说明导航 | 进入数据与说明       |

│ [活跃] [待处理] [进行中]   │

│ 语文 · 录播课 · 待处理     │
│            [加入今日重点] │

│ 数学 · 刷题 · 进行中       │
│            [已在今日重点] │
│                         │

│            [加入今日重点] │

└─────────────────────────┘

## 4.6 空状态

### 情况A：整个任务库为空

显示：

> 任务库还是空的
> 创建一个任务，只需要填写任务名称。

操作：

* “新建第一个任务”

### 情况B：当前筛选结果为空

例如用户选择“已完成”，但没有已完成任务。

显示：

> 暂无已完成任务

操作：

* “查看活跃任务”

不同筛选状态使用对应文字，不使用统一的“没有数据”。

### 情况C：已移除列表为空

显示：

> 暂无已移除任务
> 被移除的任务会保留在这里，直到你恢复或永久删除。

不显示清理建议或任务数量压力提示。

## 4.7 错误状态

### 任务列表读取失败

显示：

> 无法读取任务列表。请重新加载页面。

操作：

* “重新加载”
* “前往数据与说明”

### 加入今日重点失败

显示：

> 没有成功加入今日重点，任务仍保留在任务库中。

操作：

* “重试”

### 永久删除失败

显示：

> 任务没有被删除，原数据仍然保留。

操作：

* “重试”
* “返回”

# 5. 页面三：数据与说明

## 5.1 页面目的

“数据与说明”页面用于：

1. 导出当前浏览器中的任务数据；
2. 从兼容备份文件恢复数据；
3. 清除当前浏览器中的应用数据；
4. 说明本地保存的风险；
5. 说明隐私、安全和版权边界；
6. 说明第一版产品范围。

该页面不提供：

* 账号管理；
* 云同步设置；
* 个性化主题；
* 深色模式；
* 通知设置；
* 统计开关；
* 广告设置；
* AI设置。

## 5.2 页面区域

### 区域A：本地数据说明

显示明确说明：

> 学习任务默认保存在当前浏览器中，产品服务器不主动接收任务正文。清除浏览器数据、更换设备或浏览器环境可能导致记录丢失。

同时说明：

> 本地保存不等于绝对安全或完全匿名。共用设备、浏览器扩展、设备丢失和导出文件泄露仍可能带来风险。

### 区域B：导出备份

包含：

* “导出备份”按钮；
* 导出范围说明；
* 文件风险提示。

说明内容：

* 导出文件包含全部任务及任务字段；
* 文件可能包含成绩、计划和个人备注；
* 导出文件不会自动上传；
* 用户需要自行保管文件。

### 区域C：导入备份

包含：

* “选择备份文件”按钮；
* 导入规则说明。

必须说明：

> 导入会替换当前浏览器中的应用数据，不会自动合并。

选择文件后进入导入预览界面，不立即写入数据。

### 区域D：清除本地数据

包含：

* 危险操作说明；
* “清除本地数据”按钮。

说明文字：

> 此操作只清除当前浏览器中由本应用保存的数据，不能删除已经导出的文件、系统备份或其他位置的副本。

点击后打开二次确认对话框。

### 区域E：隐私与安全说明

至少包括：

* 无需注册；
* 默认不上传任务正文；
* 公共网页托管平台可能产生基础访问日志；

# 7. 二级界面：从现在重新安排

## 7.1 界面目的

帮助用户在计划偏离后，对未完成任务逐项作出下一步决定。

该界面不是自动计划工具，不提供AI建议，不自动延期。

## 7.2 进入界面的任务范围

默认列出：

* 今日重点中的待处理任务；
* 今日重点中的进行中任务；
* 今日重点中的部分完成任务；
* 用户主动选择处理的过往重点任务。

不默认列出：

* 已完成任务；
* 已移除任务；
* 普通任务库中的所有任务。

## 7.3 页面区域

### 区域A：页面说明

显示：

> 根据现在的情况，重新决定每项未完成任务怎么处理。你可以暂时跳过，系统不会自动延期。

### 区域B：待处理任务列表

每个任务显示：

* 任务名称；
* 当前状态；
* 科目和学习形式，可选；
* 当前完成标准，可选；
* 六种处理方式。

处理方式：

1. 继续；
2. 缩小；
3. 拆分；
4. 延期；
5. 移回任务库；
6. 移除。

### 区域C：按选择显示的补充字段

#### 选择继续

不要求填写额外内容。

#### 选择缩小

显示：

* 修改后的任务名称；
* 修改后的内容范围；
* 修改后的完成标准。

用户至少修改其中一项。

系统不得自动生成缩小方案。

#### 选择拆分

显示：

* 新任务名称输入框；
* “添加一个任务”按钮；
* 每个新任务是否加入今日重点的选项。

至少需要两个新任务名称。

系统不得自动生成拆分内容。

#### 选择延期

显示：

* 新计划日期。

新日期必须晚于今天。

延期后：

* 移出今日重点；
* 不自动在新日期加入今日重点；
* 不提供通知或提醒。

#### 选择移回任务库

显示结果说明：

> 任务将移出今日重点并清除计划日期，保留在任务库。

#### 选择移除

显示结果说明：

> 任务将进入已移除列表，之后仍可恢复或永久删除。

### 区域D：结果预览

显示每个任务确认后将发生什么。

示例：

```text
数学函数练习
→ 缩小为“完成函数练习第1—5题”
→ 保留在今日重点

英语词组复习
→ 延期至8月5日
→ 移出今日重点
```

### 区域E：底部操作

包含：

* 取消；
* 保存已选择的处理结果。

用户可以只处理部分任务。

未选择处理方式的任务：

* 保持原状态；
* 保持原日期；
* 不自动延期；
* 不自动加入下一天重点；
* 等待用户之后主动处理。

普通任务仍然只要求填写任务名称。

“今日重点1—3项”只作为非阻断建议。

未完成任务保持原状态，必须等待用户主动重新决定；系统不得自动延期、自动加入下一天重点或自动删除。

数据与说明页面明确说明：

> 本地保存不等于绝对安全或完全匿名。

---

# 13. 原型制作建议顺序

页面原型应按以下顺序制作和验证：

1. 今日页面空状态；
2. 快速创建任务；
3. 今日重点任务卡片及状态变化；
4. 任务库及状态筛选；
5. 任务详情／编辑；
6. 从现在重新安排；
7. 数据导入、导出和清除；
8. 各页面错误状态；
9. 手机端导航和布局；
10. 桌面端导航和布局。

第一轮原型验证应重点观察：

* 用户是否知道只填写任务名称即可保存；
* 用户是否理解今日重点不是全部任务；
* 用户是否理解1—3项只是建议；
* 用户是否能找到开始、部分完成和完成操作；
* 用户是否理解已移除与永久删除的区别；
* 用户是否理解未完成任务不会自动顺延；
* 用户是否理解导入会替换当前数据；
* 用户是否理解本地保存仍然存在安全和丢失风险。
