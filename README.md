# OpenStudy Planner

面向广东“3+证书”考生的本地优先开源学习任务规划工具：帮助你把学习事项变成可执行任务，并在计划偏离后自己决定下一步。

## 适合谁

它面向希望用轻量网页管理语文、数学、英语和其他学习事项的广东“3+证书”考生。无需账号或登录。

## MVP 核心闭环

创建任务 → 选择今日重点 → 开始执行 → 标记结果 → 对未完成任务重新决策

## 当前已实现

- 只填写任务名称即可创建任务；科目、学习形式、内容范围、日期、备注、下一步、完成标准、实际用时和实际完成情况均可选。
- 在今日和任务库之间管理重点任务；1—3 项只是建议，第 4 项及以上仍可添加。
- 使用待处理、进行中、部分完成、已完成、已移除五种状态；已移除可恢复，永久删除需要确认。
- 对未完成的今日或过往重点任务手动选择：继续、缩小、拆分、延期、移回任务库或移除。未完成任务不会自动顺延。
- 在当前浏览器中导出 JSON 备份、预览后完整替换导入，以及只清除本应用保存的数据。
- 提供手机和桌面基础布局，以及本地保存、隐私、安全和版权边界说明。

## 第一版明确不做

不包含 AI 规划或建议、番茄钟/专注计时、账号、云同步、统计图表、打卡、排行榜、社交、成绩或录取预测、自动提醒、PWA、深色模式、打印、日历排程或科目专用复杂表单。

也不提供课程、教材或题库正文。

## 在线使用

直接打开 [OpenStudy Planner 在线版](https://rkgamemer.github.io/openstudy-planner/) 即可使用。

## 本地运行

需要 Node.js 20.19 或更高版本，以及 npm。

```bash
npm ci
npm run dev
```

随后在终端显示的本地地址打开应用。

常用检查命令：

```bash
npm run lint
npm run test
npm run build
```

## GitHub Pages 部署

本项目已部署至 GitHub Pages：<https://rkgamemer.github.io/openstudy-planner/>。

仓库包含 GitHub Actions 工作流：推送到 `main` 或手动触发后，依次执行 `npm ci`、lint、test 和 build；全部通过后才部署 `dist` 到 GitHub Pages。

如需为分叉仓库或新的部署环境配置 GitHub Pages，请在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，并确认仓库允许 Actions 写入 Pages。Vite 的基础路径固定为 `/openstudy-planner/`，应用使用 HashRouter，因此无需服务器端路由重写。

## 数据、隐私与安全边界

- 无需账号；任务默认保存在当前浏览器，正常创建、编辑和查看不会上传任务名称、备注、下一步或完成标准等正文。
- 本地保存不等于绝对安全或完全匿名。共用设备、浏览器扩展、设备丢失、浏览器数据清除、更换设备或浏览器环境，都可能造成泄露或记录丢失。
- 清除浏览器数据可能导致任务记录丢失。应用的“清除本地数据”只删除本应用的浏览器键，不能删除导出的文件、系统备份或其他副本。
- 导出备份可能包含任务、学习计划、成绩信息、实际完成情况和个人备注；请自行妥善保管。
- GitHub Pages 等公共托管服务可能产生基础访问日志。项目不接入广告、跨站追踪或任务正文分析。
